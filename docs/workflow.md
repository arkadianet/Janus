# Workflow (idea → product)

Do not start a crate until the golden hoard notes have real paths.

```text
Loop 0  Contract     DESIGN + PRODUCT + cases     (this PR)
Loop 1  Catalogue    Phase A CLI on golden hoard  0.1.0
Loop 2  Live with it Freeze family_key
Loop 3  Browse       Phase B UI                   0.2.0
Loop 4  Outward      Phase C radar, then D fetch  0.3.0 → 1.0.0
Loop 5  Polish       install, doctor, second OS
Loop 6  Public       Ship A+B if C/D are late
```

Rules:

- Dogfood on real disks every loop. Synthetic-only means we are guessing.
- Identity before chrome. Wrong families are not a UI bug.
- Fixtures grow. Never delete an awkward case.
- Read the never-list before each milestone.

[golden-hoard.md](golden-hoard.md), unplug a drive, run Ollama/LM Studio
layouts on your machine.
